What happens next

When you press Find a match, the app marks you as searching, asks GAS for an available opponent, then claims an open game from the Games sheet. The match page reads the game description directly from the sheet and waits for either player to report a loss.

Your ELO will be updated only after the result is resolved in the backend and written to Game History.
